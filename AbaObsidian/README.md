# VWA-Game Vault

1. Ordner `VWA-Game` in Obsidian über **Ordner als Vault öffnen** laden.
2. **Einstellungen → Community-Plugins**: Restricted Mode ausschalten, dann installieren:
   Dataview (in den Dataview-Einstellungen *JavaScript Queries* aktivieren), Tasks, Templater (optional), Kanban, Obsidian Git (optional).
3. Kern-Plugin **Vorlagen** aktivieren; Ordner `_Templates` ist bereits eingestellt.
4. Mit `_Dashboard.md` starten und Forschungsfrage in `01_Thema` ausfüllen.

Code gehört in ein separates Git-Repo, nicht in den Vault.
